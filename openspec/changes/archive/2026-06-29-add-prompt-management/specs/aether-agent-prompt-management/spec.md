# Prompt 模板管理

## 需求说明（前提/操作/结果）

---

## ADDED Requirements

<a name="req-1"></a>
### Requirement: 1. Prompt 模板 CRUD

<a name="openspec-req-1"></a>系统应当（SHALL）提供 Prompt 模板的创建、查询、更新、删除操作，支持变量占位符和分类标签。

#### 场景: 创建 Prompt 模板
- **前提**：用户有模板管理权限
- **操作**：填写模板名称、内容（支持 `{{variable}}` 占位符）、选择分类和标签
- **结果**：模板保存成功，版本号为 1

#### 场景: 模板列表查询
- **前提**：系统中存在多个模板
- **操作**：按名称、分类、标签筛选
- **结果**：分页展示模板列表

---

<a name="req-2"></a>
### Requirement: 2. 模板版本管理

<a name="openspec-req-2"></a>系统应当（SHALL）在每次模板保存时自动生成新版本快照，支持版本回滚。

#### 场景: 保存生成新版本
- **前提**：模板已有版本
- **操作**：用户编辑模板内容后保存
- **结果**：新版本号自增，旧版本保留

---

<a name="req-3"></a>
### Requirement: 3. A/B 实验

<a name="openspec-req-3"></a>系统应当（SHALL）支持为同一场景配置多个模板版本，按比例分流进行 A/B 实验。

#### 场景: 配置实验分流
- **前提**：存在同一场景的多个模板版本
- **操作**：配置实验：版本 A 占 70%，版本 B 占 30%
- **结果**：后续调用按配置比例随机分配模板版本

---

<a name="req-4"></a>
### Requirement: 4. 调用记录追踪

<a name="openspec-req-4"></a>系统应当（SHALL）记录每次模板调用的详细信息，支持查询和统计。

#### 场景: 查看调用记录
- **前提**：模板已被调用
- **操作**：按模板 ID、时间范围查询
- **结果**：展示调用记录：模板版本、输入/输出摘要、Token 消耗、耗时
