# AI 流程引擎（Flow Engine）

## 流程执行引擎 需求说明（前提/操作/结果）

> 描述 AI 流程引擎的业务场景与边界。引擎负责解析流程定义、按 DAG 拓扑顺序执行节点、处理条件路由与异常。

## ADDED Requirements
（新增用户故事）

<a name="req-1"></a>
### Requirement: 1. 流程定义解析与校验

<a name="openspec-req-1"></a>系统应当（SHALL）解析前端保存的流程定义 JSON，校验拓扑完整性后转换为可执行图。

#### 场景: 合法流程定义解析
- **前提**：前端提交包含开始节点、结束节点和有效连线的流程定义 JSON
- **操作**：引擎接收并解析 JSON 定义
- **结果**：生成内部可执行图（适配 CompiledGraph），节点按拓扑排序，校验通过

#### 场景: 缺少开始或结束节点
- **前提**：流程定义 JSON 中缺少开始节点或结束节点
- **操作**：引擎校验流程定义
- **结果**：返回校验错误，明确指出缺少哪类节点，拒绝执行

#### 场景: 存在环路
- **前提**：流程定义中存在节点间环路连接
- **操作**：引擎执行 DAG 校验
- **结果**：返回校验错误，指出环路路径，拒绝执行

<a name="req-2"></a>
### Requirement: 2. 节点执行器调度

<a name="openspec-openspec-req-2"></a>系统应当（SHALL）按节点类型分派到对应执行器，支持流式输出与上下文传递。

#### 场景: AI 节点执行
- **前提**：流程执行到 AI 节点，上下文中已有前序节点的输出
- **操作**：引擎将节点配置（模型、Prompt、参数）与上下文组装，调用 LLM
- **结果**：LLM 响应写入上下文，供后续节点使用；支持 SSE 流式输出

#### 场景: 知识库节点执行
- **前提**：流程执行到 AI 知识库节点
- **操作**：引擎根据节点配置的知识库 ID 和检索参数，执行 RAG 检索
- **结果**：检索结果注入上下文，作为后续 AI 节点的参考知识

#### 场景: 分支节点路由
- **前提**：流程执行到分支节点，上下文中已有条件变量值
- **操作**：引擎按节点配置的条件表达式逐一匹配
- **结果**：命中条件分支，执行对应路径；无命中时走默认分支（若有）

#### 场景: 脚本节点执行
- **前提**：流程执行到脚本节点
- **操作**：引擎在沙箱中执行用户编写的脚本（Groovy/JS），传入上下文变量
- **结果**：脚本输出写回上下文；执行超时（默认 30s）自动终止

---

<a name="req-3"></a>
### Requirement: 3. 执行上下文与数据流

<a name="openspec-req-3"></a>系统应当（SHALL）维护流程执行上下文，支持节点间数据传递与变量引用。

#### 场景: 上下文变量传递
- **前提**：前序节点输出结果已写入上下文
- **操作**：后续节点通过变量引用语法（如 `{{node_1.output}}`）引用前序输出
- **结果**：引擎在执行前完成变量替换，节点获取实际值

#### 场景: 开始节点输入参数
- **前提**：流程开始节点定义了输入参数（如 `question`）
- **操作**：用户调用流程时传入参数值
- **结果**：参数注入执行上下文，后续节点可引用

---

<a name="req-4"></a>
### Requirement: 4. 异常处理与重试

<a name="openspec-req-4"></a>系统应当（SHALL）在节点执行失败时提供异常处理机制，支持配置重试策略。

#### 场景: 节点执行失败
- **前提**：某节点执行过程中抛出异常（如 LLM 超时、脚本错误）
- **操作**：引擎捕获异常
- **结果**：流程暂停执行，异常信息记录到执行日志；若配置了重试，按策略自动重试

#### 场景: 重试策略配置
- **前提**：节点配置了重试策略（最大重试次数、间隔）
- **操作**：节点执行失败
- **结果**：引擎按配置间隔重试，达到最大次数后仍失败则标记节点为失败状态
