# AI 流程集成（Flow Integration）

## 流程与应用集成 需求说明（前提/操作/结果）

> 描述 AI 流程与 AI 应用的集成方式，包括应用关联流程、流程作为 MCP 插件暴露、API 调用等场景。

---

## ADDED Requirements
（新增用户故事）

<a name="req-1"></a>
### Requirement: 1. 应用关联流程

<a name="openspec-req-1"></a>系统应当（SHALL）支持 AI 应用关联一个已发布的流程，对话请求优先走流程编排路径。

#### 场景: 应用绑定流程
- **前提**：存在已发布且启用的流程
- **操作**：用户在应用配置中选择关联一个流程
- **结果**：应用保存 flowId 关联；后续该应用的对话请求走流程引擎执行路径

#### 场景: 应用解绑流程
- **前提**：应用已关联流程
- **操作**：用户在应用配置中清除流程关联
- **结果**：应用恢复默认编排路径（AgentHubRouter 意图路由）

#### 场景: 关联流程被禁用
- **前提**：应用已关联流程，该流程被管理员禁用
- **操作**：用户向该应用发送对话请求
- **结果**：系统返回错误提示"关联流程已禁用"，不降级到默认路由

<a name="req-2"></a>
### Requirement: 2. 流程 API 调用

<a name="openspec-req-2"></a>系统应当（SHALL）提供流程的 REST API 调用入口，支持同步和 SSE 流式两种模式。

#### 场景: 同步调用流程
- **前提**：流程已发布且启用
- **操作**：外部系统通过 POST `/api/agent-hub/flow/{flowId}/invoke` 传入参数
- **结果**：引擎执行流程并返回完整结果（JSON）

#### 场景: SSE 流式调用流程
- **前提**：流程已发布且启用
- **操作**：外部系统通过 POST `/api/agent-hub/flow/{flowId}/stream` 传入参数
- **结果**：引擎执行流程，通过 SSE 逐节点推送执行进度和中间结果

---

<a name="req-3"></a>
### Requirement: 3. 流程作为 MCP 插件

<a name="openspec-req-3"></a>系统应当（SHALL）支持将已发布流程注册为 MCP 工具，供 ReactAgent 在对话中自动调用。

#### 场景: 流程注册为 MCP 工具
- **前提**：流程已发布且启用，流程开始节点定义了输入参数
- **操作**：管理员在流程管理中点击"发布为 MCP 工具"
- **结果**：系统自动生成 MCP Tool 描述（名称=流程名，描述=流程描述，参数=开始节点输入参数），注册到 ToolCatalog

#### 场景: Agent 对话中调用流程插件
- **前提**：流程已注册为 MCP 工具
- **操作**：ReactAgent 在对话中识别到需要调用该工具
- **结果**：Agent 自动调用流程，获取执行结果并整合到回复中

---

<a name="req-4"></a>
### Requirement: 4. 流程执行记录与可观测性

<a name="openspec-req-4"></a>系统应当（SHALL）记录每次流程执行的完整日志，支持查询和审计。

#### 场景: 查看执行记录列表
- **前提**：流程已执行过多次
- **操作**：用户访问流程执行记录页面
- **结果**：展示执行记录列表：执行 ID、流程名、触发方式（API/应用/MCP）、状态、耗时、Token 消耗、创建时间

#### 场景: 查看执行详情
- **前提**：存在一条执行记录
- **操作**：用户点击某条记录
- **结果**：展示执行详情：每个节点的输入/输出、耗时、Token 消耗、异常信息（若有）、完整执行轨迹
