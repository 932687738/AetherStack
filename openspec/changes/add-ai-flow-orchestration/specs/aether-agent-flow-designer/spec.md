# AI 流程设计器（Flow Designer）

## 可视化流程设计 需求说明（前提/操作/结果）

> 描述 AI 流程设计器的业务场景与边界。设计器为用户提供可视化画布，通过拖拽节点和连线构建 AI 工作流。

---

## ADDED Requirements
（新增用户故事）

<a name="req-1"></a>
### Requirement: 1. 画布拖拽编辑

<a name="openspec-req-1"></a>系统应当（SHALL）提供可视化画布，支持用户通过拖拽方式添加节点、连线建立流程拓扑。

#### 场景: 拖拽节点到画布
- **前提**：用户已进入流程设计器页面，左侧节点面板已加载可用节点类型列表
- **操作**：用户从左侧节点面板拖拽一个节点类型（如"AI 节点"）到画布区域
- **结果**：画布上出现对应节点实例，可自由拖拽定位；节点自动分配唯一 ID

#### 场景: 节点间连线
- **前提**：画布上已存在至少两个节点
- **操作**：用户从源节点的输出端口拖拽连线到目标节点的输入端口
- **结果**：两节点间建立有向连接，连线显示数据流向箭头；不允许形成环路（DAG 约束）

#### 场景: 删除节点或连线
- **前提**：画布上已存在节点和连线
- **操作**：用户选中节点或连线后按 Delete 键或点击右键删除
- **结果**：节点及其关联连线被移除；若删除的是中间节点，前后连线一并清除

<a name="req-2"></a>
### Requirement: 2. 节点配置面板

<a name="openspec-req-2"></a>系统应当（SHALL）在用户选中节点时展示属性配置面板，支持按节点类型动态渲染配置表单。

#### 场景: 配置 AI 节点参数
- **前提**：用户在画布上选中一个"AI 节点"
- **操作**：右侧属性面板展示 AI 节点配置项：模型选择、Prompt 模板、温度参数、最大 Token 数
- **结果**：用户可配置各参数并自动保存到流程定义中

#### 场景: 配置分支节点条件
- **前提**：用户在画布上选中一个"分支节点"
- **操作**：右侧属性面板展示条件配置：条件变量、比较运算符、期望值；支持多分支
- **结果**：每个分支对应一条输出连线，条件表达式保存到节点配置

#### 场景: 配置知识库节点
- **前提**：用户在画布上选中一个"AI 知识库节点"
- **操作**：右侧属性面板展示：知识库选择（多选）、Top-K、相似度阈值
- **结果**：节点配置保存所选知识库 ID 及检索参数

---

<a name="req-3"></a>
### Requirement: 3. 流程实时调试

<a name="openspec-req-3"></a>系统应当（SHALL）支持在画布上实时运行流程并查看每个节点的输入/输出。

#### 场景: 启动调试运行
- **前提**：流程画布上存在完整的流程拓扑（有开始节点和至少一个结束节点）
- **操作**：用户点击"调试运行"按钮，输入测试参数
- **结果**：流程开始执行，画布上节点按执行顺序高亮，每个节点执行完成后展示输入/输出内容

#### 场景: 查看节点执行日志
- **前提**：流程调试运行中或已完成
- **操作**：用户点击某个已执行节点
- **结果**：右侧面板展示该节点的详细日志：输入数据、LLM 请求/响应、耗时、Token 消耗、异常信息（若有）

#### 场景: 调试运行异常
- **前提**：流程中存在配置错误的节点
- **操作**：用户启动调试运行
- **结果**：流程执行到错误节点时停止，画布上该节点标红，展示错误详情；已完成节点保持高亮状态

<a name="req-4"></a>
### Requirement: 4. 节点类型体系

<a name="openspec-req-4"></a>系统应当（SHALL）提供以下内置节点类型，并支持后续扩展。

#### 场景: 内置节点类型清单
- **前提**：用户打开节点面板
- **操作**：查看可用节点类型列表
- **结果**：展示以下节点类型：开始节点、结束节点、AI 节点（LLM 调用）、AI 知识库节点（RAG 检索）、分类节点、分支节点（条件路由）、脚本节点（Groovy/JS）、HTTP 请求节点、子流程节点、直接回复节点

#### 场景: 节点类型扩展
- **前提**：开发者需要新增自定义节点类型
- **操作**：实现节点执行器接口（后端）+ 注册节点配置面板（前端）
- **结果**：新节点类型出现在节点面板中，可拖拽使用
