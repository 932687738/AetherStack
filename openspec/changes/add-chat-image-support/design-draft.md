# AI 对话图片支持 - 整体方案

## 一、核心问题
**要解决什么问题**：对话界面不支持图片发送和展示，无法利用 VL 多模态模型。

## 二、整体思路
- 前端聊天输入框增加图片上传（拖拽/粘贴/点击），上传后获取 URL
- 后端 ChatClient 调用时支持多模态消息（Spring AI `UserMessage` + `Media`）
- AI 回复中的 Markdown 图片语法自动渲染为 `<img>` + 点击查看大图
- 图片存储：本地文件 + 可配置 OSS

## 三、技术选型
| 功能场景 | 技术组件 | 使用理由 |
|---------|---------|---------|
| 图片上传 | Spring MVC MultipartFile | 标准文件上传 |
| VL 模型 | Spring AI Media | 原生多模态支持 |
| 图片渲染 | react-markdown + 自定义 renderer | 与现有 Markdown 渲染一致 |

## 四、影响范围
- 后端：ChatClient 调用增加多模态消息支持
- 前端：聊天组件增加图片上传/展示

## 五、数据设计
```sql
-- 修改消息表（或会话历史表）
-- 新增字段：media_urls jsonb（消息关联的图片 URL 列表）
```

## 六、约束与风险
- 图片大小限制 10MB
- VL 模型需额外配置（非所有模型支持图片）
