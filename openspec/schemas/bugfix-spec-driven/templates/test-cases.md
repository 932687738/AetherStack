# 测试用例（bugfix-spec-driven）

> 用例主体需遵循 `[S]` / `[C]` Markdown 导入规则；以下模板用于约束缺陷修复验证结构。

## 0. 测试基线来源（按需）
- OpenSpec 基线：`bug-report.md` + `fix-plan.md`
- 外部测试基线：`无` / `<路径>`（仅在用户提供外部测试稿时填写）
- 采用方式：`仅 OpenSpec` / `以外部测试稿为主并合并 OpenSpec` / `冲突项待确认`
