# 常见错误清单

本文档整理开发中常见错误及修复方案，按严重级别分类。

---

## 高优先级问题（影响生产环境）

### 1. 向已有父类添加抽象方法

**问题**：破坏性变更，导致所有子类编译失败

**修复方案**：
- **推荐**：提供默认实现（空方法或抛出异常）
- **备选**：使用接口 + default 方法
- **慎用**：修改接口定义（需评估所有实现类）

### 2. 日志问题

**错误做法**：
- 使用英文
- 缺少关键信息
- 未打印堆栈

**正确做法**：
- 使用中文描述
- 包含关键业务标识（订单号、用户ID等）
- 异常日志必须打印堆栈：`log.error("处理失败，orderId=={}", orderId, e)`

### 3. MetricsUtil 监控埋点问题

**问题**：使用变量拼接名称，导致监控指标暴增

**错误做法**：`MetricsUtil.recordOne("error." + errorType)`

**正确做法**：使用固定名称，可穷举

### 4. 并发安全问题

#### 4.1 线程池创建

**问题**：Executors 创建的线程池可能导致 OOM

**正确做法**：
- 使用 ThreadPoolExecutor
- 明确队列边界（有界队列）
- 设置合理的拒绝策略

#### 4.2 ThreadLocal 不清理

**问题**：导致内存泄漏或数据串号

**正确做法**：使用 try-finally 确保清理

### 5. 空指针风险

**常见场景**: 包装类拆箱、== 比较对象、RPC 返回值链式调用未判空

### 6. 金额计算问题

**错误做法**: 使用浮点数计算金额

**正确做法**: 使用 BigDecimal，字符串构造

---

## 中优先级问题（影响可维护性）

### 7. 接口契约违反

**问题**：修改带有 `@Override` 注解的方法签名，导致无法实现接口

**修复策略优先级**：向后兼容 > 方法重载 > 修改接口

**推荐方案：向后兼容（委托模式）**

```
原方法（实现接口）→ 调用新方法（带默认参数）
新方法（私有）→ 实际业务逻辑
```

**检查清单**：
- 方法是否实现了接口？（检查 `@Override` 注解）
- 接口定义的方法签名是什么？
- 是否有其他实现类或调用方？
- 修改后是否破坏向后兼容性？

### 8. 魔法值

**问题**：使用硬编码的数字或字符串

**解决方案**：定义常量或枚举

### 9. 方法过长

**问题**：方法超过 50 行，难以理解和维护

**解决方案**：抽取 Handler 或私有方法，保持方法职责单一

### 10. 注释位置错误

**问题**：注释在行后

**正确做法**：注释在行前，便于阅读

### 11. 重复造轮子

**问题**：自己实现已有功能

**解决方案**：使用工程中已有的工具类（StringUtils、CollectionUtils等）

### 12. 实体类不规范

**要求**：
- 使用 Lombok 注解（@Data、@Builder等）
- 字段添加 JavaDoc 注释

## 低优先级问题（完善性）

### 13. 异常处理不规范

**错误做法**：
- 捕获 Exception 吞没堆栈
- 重新包装异常丢失原堆栈

**正确做法**：
- 捕获具体异常
- 保留原异常作为 cause
- 异常日志包含关键信息

### 14. 集合操作陷阱

**常见问题**：
- 修改不可变集合（Arrays.asList）
- foreach 中删除元素
- 集合未初始化容量导致多次扩容

**解决方案**：
- 创建可变集合
- 使用迭代器或 removeIf
- 已知大小时初始化容量

### 15. SQL 相关问题

#### 15.1 SQL 注入风险

**错误做法**：字符串拼接 SQL

**正确做法**：使用参数化查询（#{param}）

#### 15.2 未使用索引

**问题**：查询条件未命中索引

**常见原因**：前置通配符、函数操作、类型不匹配

---

## 配置相关问题

### 16. 高风险配置

**生产环境严禁**：
- 暴露数据库控制台
- 暴露所有监控端点
- 开启 SQL 日志

### 17. 超时配置不一致

**要求**：客户端超时 < 网关超时 < 负载均衡超时

**示例**：客户端 10s < 网关 15s < 负载均衡 20s

---

## 修复优先级判断

| 优先级 | 判断标准 | 示例 |
|--------|----------|------|
| **CRITICAL** | 影响生产环境、可能导致宕机/数据丢失/安全漏洞 | 线程池无界、SQL注入、敏感信息泄露 |
| **HIGH** | 影响性能、可维护性、缺失错误处理 | N+1 查询、日志无关键信息、监控缺失 |
| **SUGGESTION** | 代码风格、优化机会 | 注释位置、命名不规范、魔法值 |
